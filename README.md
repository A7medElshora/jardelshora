# مخزون شوره

أنت مطور Full Stack وخبير UX/UI. قم بإنشاء نظام ويب احترافي بالكامل باللغة العربية باسم:



نظام جرد وإدارة مخزون الشوره ماركت



متطلبات عامة



- واجهة عربية بالكامل (RTL).

- تصميم احترافي حديث يشبه الأنظمة التجارية الكبيرة.

- متجاوب مع الموبايل والتابلت والكمبيوتر.

- استخدام قاعدة بيانات سحابية Cloud Database لتخزين البيانات بشكل دائم.

- يفضل استخدام Supabase أو Firebase.

- جميع البيانات تحفظ تلقائياً.

- نظام صلاحيات وتسجيل دخول للمشرف.

- لوحة تحكم احترافية.

- إمكانية تصدير جميع التقارير إلى Excel.

- إمكانية الطباعة PDF.

- دعم البحث والفلترة.

- استخدام Charts ورسوم بيانية للإحصائيات.

تحتوي على 4 بطاقات رئيسية:



1. الجرد اليومي

2. الجرد الأسبوعي

3. الجرد الشهري

4. المضاف



مع عرض إحصائيات سريعة:



- إجمالي الأصناف

- إجمالي الوارد

- إجمالي الصادر

- إجمالي الأرباح

- أصناف قاربت على النفاد



---



صفحة الجرد اليومي



تحتوي على جدول بالأعمدة التالية:



| العدد |

| الصنف |

| سعر الجملة |

| سعر القطاعي |

| المستهلك |



داخل عمود "المستهلك" يوجد أعمدة فرعية لأيام الأسبوع:



- الأحد

- الإثنين

- الثلاثاء

- الأربعاء

- الخميس

- الجمعة

- السبت



مثال:



عدد = 10



صنف = كليوباترا



سعر الجملة = 50



سعر القطاعي = 55



في يوم الأحد تم بيع 7 علب.



يقوم النظام تلقائياً بحساب:



- إجمالي الجملة للمبيعات

- إجمالي القطاعي للمبيعات

- إجمالي الربح



المعادلات:



إجمالي الجملة = الكمية المباعة × سعر الجملة



إجمالي القطاعي = الكمية المباعة × سعر القطاعي



الربح = إجمالي القطاعي - إجمالي الجملة



وفي أسفل كل يوم من أيام الأسبوع تظهر بطاقات ملونة:



- بطاقة خضراء لإجمالي القطاعي

- بطاقة زرقاء لإجمالي الجملة

- بطاقة برتقالية للأرباح



ويتم تحديثها لحظياً.

إظهار تنبيه:

إظهار تنبيه أحمر:



"الصنف نفد من المخزون"



---



صفحة المضاف (الوارد)



تحتوي على الأعمدة التالية:



| التاريخ |

| العدد |

| الصنف |

| سعر الجملة |

| جهة الشراء |



مثال:



التاريخ: 22/06/2026



الصنف: كليوباترا



العدد: 30



سعر الجملة: 51.5



جهة الشراء: شركة كليوباترا للدخان



---



معالجة اختلاف الأسعار



إذا كان الصنف موجوداً مسبقاً:



مثال:



الكمية القديمة = 10



السعر القديم = 50



تمت إضافة:



30 قطعة



بسعر 51.5



يجب على النظام:



1. تحديث الكمية:

   10 + 30 = 40



2. حساب متوسط السعر المرجح (Weighted Average Cost)



المعادلة:



((10 × 50) + (30 × 51.5))

÷

(10 + 30)



واستخدام الناتج كسعر جملة جديد للصنف.



---



سجل تعديل الأسعار



عند تغيير السعر بسبب المتوسط:



يظهر إشعار جانبي دائم:



تم تحديث سعر الصنف "كليوباترا"



السعر القديم: 50 جنيه



السعر الجديد بعد المتوسط: 51.13 جنيه



سبب التعديل:

تم إضافة كمية جديدة بسعر مختلف ولذلك تم احتساب متوسط التكلفة.



كما يتم حفظ هذه العملية داخل:



سجل التعديلات (Audit Log)



مع:



- التاريخ

- المستخدم

- السعر القديم

- السعر الجديد

- سبب التعديل
